This module provisions an object storage bucket on Oracle Cloud Infrastructure (OCI) and an Amazon DynamoDB to support Terraform state storage and locking. Amazon DynamoDB is used because there is an alway free tier available while the Oracle NoSQL Always Free Tier is not available in regions other than US West (Phoenix) (us-phoenix-1).
